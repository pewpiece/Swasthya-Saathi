# System Usability Scale (SUS)

Give it **after** the tasks, once per participant. It takes about 3 minutes.
Do not discuss answers while they fill it in. If a participant cannot read, the
facilitator reads each sentence aloud and ticks what they say, without comment.

## Standard SUS (English)
Rate each statement from **1 = strongly disagree** to **5 = strongly agree**.
("system" = this app)

| # | Statement | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | I think that I would like to use this app frequently. | | | | | |
| 2 | I found the app unnecessarily complex. | | | | | |
| 3 | I thought the app was easy to use. | | | | | |
| 4 | I think that I would need the support of a technical person to be able to use this app. | | | | | |
| 5 | I found the various functions in this app were well integrated. | | | | | |
| 6 | I thought there was too much inconsistency in this app. | | | | | |
| 7 | I would imagine that most people would learn to use this app very quickly. | | | | | |
| 8 | I found the app very cumbersome to use. | | | | | |
| 9 | I felt very confident using the app. | | | | | |
| 10 | I needed to learn a lot of things before I could get going with this app. | | | | | |

## Scoring
1. For **odd** items (1, 3, 5, 7, 9): contribution = **answer - 1**.
2. For **even** items (2, 4, 6, 8, 10): contribution = **5 - answer**.
3. Add the ten contributions (0 to 40) and **multiply by 2.5** -> a score from 0 to 100.
4. Average the scores of all participants.

Example: answers 4,2,5,1,4,2,5,1,4,2 -> contributions 3,3,4,4,3,3,4,4,3,3 = 34 -> **85**.

Reading the score (not a percentage): about **68 is average**; 80 or more is
good; below 50 means serious usability problems. With only 3-5 people it is a
guide, not proof. Always read it together with the task results and comments.

## Plain-language version (for the parents)
Same ten questions, same scoring (they are in the same order, so the score is
calculated exactly as above). Use big print. Offer five choices with words:

**1 = No, not at all  ·  2 = A little  ·  3 = In between  ·  4 = Mostly yes  ·  5 = Yes, very much**

| # | Say / write | Answer 1-5 |
|---|---|---|
| 1 | I would like to use this app often. | |
| 2 | The app was more complicated than it needed to be. | |
| 3 | The app was easy to use. | |
| 4 | I would need someone who knows phones to help me use it. | |
| 5 | The parts of the app fit together well. | |
| 6 | Some things in the app worked differently from other things. | |
| 7 | I think most people would learn this app quickly. | |
| 8 | The app was awkward or tiring to use. | |
| 9 | I felt sure of myself when I used it. | |
| 10 | I had to learn many things before I could start. | |

Tip: use five large boxes, or five circles from small to big, so nobody needs
to read numbers.
